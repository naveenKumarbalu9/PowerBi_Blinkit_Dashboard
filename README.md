# Blinkit Sales Dashboard

## 📌 Project Description

The **Blinkit Sales Dashboard** is a Power BI project designed to analyze sales performance and provide business insights using Blinkit sales data.

The dashboard helps understand sales, product performance, outlet performance, customer preferences, and other important business metrics.

## 🚀 Features

* Sales performance analysis
* Outlet-wise sales analysis
* Product category analysis
* Item-wise sales analysis
* Outlet size and location analysis
* Customer rating analysis
* Interactive Power BI dashboard
* KPI-based business insights

## 🛠️ Technologies Used

* **Power BI**
* **Power Query**
* **DAX**
* **Excel**

## 🔄 Project Workflow

```text

      ↓
Data Transformation

      ↓
DAX Measures
      ↓

      ↓

```

## 🎯 Objective

The main objective of this project is to analyze Blinkit's sales data and create an interactive dashboard that helps identify sales trends, top-performing products, and outlet performance.

## 📊 Key KPIs

* Total Sales
* Average Sales
* Number of Items
* Average Customer Rating
* Outlet Performance
